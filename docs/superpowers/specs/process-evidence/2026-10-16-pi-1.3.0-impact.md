## Changelog 逐项对照 Picot

| 1.3.0 条目 | Picot 判定 |
| --- | --- |
| `--tools` 恢复语义（resume 保留 active tools） | 不触达：Picot 只传 `--session/--no-session/--no-tools`，从不传 `--tools`；修复默认路径即为改善 |
| `--model` 多 provider 消歧 | 不触达：Picot 不传 `--model`，模型选择走 RPC |
| kimi-coding 改 Chat Completions、models.json override 需含 `/v1` | 不触达：Picot 只读用户 models.json（provider-quota.ts），不写 |
| `sessionShareDestination`、GPT-6 缓存、模型切换丢 thinking | 上游内聚，透明继承 |
| 工具调用参数解析加固（坏 `\u`、畸形 JSON 改为报错） | 透明继承，经 RPC 对 WebView 无形状变化 |
| `ctx.ui.custom({overlay:true})` done() 修复 | 不触达：Picot 扩展只用 ctx.ui.notify/select |
| 其余 Fixed（provider/重试/Nix/打包） | 纯收益或非 Picot 平台 |
